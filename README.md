# Refresh-UHC
"Sburb: Refresh" by iSmile02, now on The Unofficial Homestuck Collection!

To install, Download "Refresh-UHC" Or it's online variant (without the locally installed images for storage's sake), extract it into your asset pack's "mods" folder, and apply within the client- it's under the MSPFAs section.

*quick note; Monobound, the HTML game on page 1646, is only playable online- regardless of what version you download. As far as I know, there is no other workaround.*
